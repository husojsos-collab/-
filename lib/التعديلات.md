# كل التعديلات اللي سويناها على panel.html

## 1) صف الزر + حالة الاتصال (جنب بعض، يتبدلوا مع اللغة)

**قبل:** الزر "احصل على كود الربط" فوق بعرض كامل، والنص "لم يبدأ الاتصال بعد" تحته بسطر منفصل.

**بعد:**
```html
<div class="pair-row" id="pairRow">
  <span class="status-pill" id="statusPill">
    <span class="dot"></span>
    <span class="i18n-status-notstarted" id="statusText">لم يبدأ الاتصال بعد</span>
  </span>
  <button class="btn i18n-pairbtn" id="pairBtn">احصل على كود الربط</button>
</div>
```
```css
.pair-row{
  display:flex;
  align-items:center;
  justify-content:space-between;
  gap:10px;
  margin-top:14px;
}
.pair-row .btn{ width:auto; flex:1; }
.pair-row .status-pill{ flex:0 0 auto; white-space:nowrap; }
```
النص أول شي بالـ DOM، فبيرتب نفسه يمين/يسار تلقائي حسب اتجاه الصفحة (`dir`) بدون أي جافاسكريبت إضافي.

## 2) تغيير وجه الأفاتار بشاشة "من انت؟" + النص تحته

**قبل:** وجه كرتوني (بشرة + شعر بنفسجي)، والنص "اضغط على الصورة أو هنا لإضافة صورة/GIF (اختياري)"

**بعد:**
```html
<label for="whoPhotoInput" class="i18n-who-photo">📷 اختر صورتك</label>
```
ووجه بوت جديد (شاشة مربعة، هوائي، عيون سماوية متوهجة، ابتسامة وردية) بدل الوجه القديم.

---

## 3) ترجمة إنجليزية كاملة لشاشات الدخول

أضفت classes بصيغة `i18n-...` لكل نص، وربطتها بقاموس `I18N` (عربي/إنجليزي) الموجود بالكود، بحيث تتبدل تلقائي مع زر اللغة 🌐:

| الشاشة | العناصر المترجمة |
|---|---|
| من انت؟ | التحية، "اختر صورتك"، خطأ الاسم، زر "دخول ومتابعة"، رابط "دخول كمالك البوت" |
| دخول المالك | العنوان، خطأ كلمة السر، زر "دخول"، رابط "نسيت كلمة السر" |
| نسيت كلمة السر (3 خطوات) | كل الوصف والأزرار ورسائل الخطأ |

كمان عدّلت الـ placeholders (بدل ما تكون بس لحقل رقم الهاتف) تشمل كل الحقول:
```js
const I18N_PLACEHOLDERS = {
  phoneNumber: { ar: 'اكتب رقمك كامل مع كود الدولة', en: 'Phone number' },
  whoName: { ar: 'اكتب اسمك (إجباري)', en: 'Enter your name (required)' },
  loginPassword: { ar: 'كلمة السر', en: 'Password' },
  verifyCode: { ar: 'اكتب الكود', en: 'Enter the code' },
  newPassword: { ar: 'كلمة السر الجديدة', en: 'New password' },
  newPasswordConfirm: { ar: 'أكد كلمة السر', en: 'Confirm password' }
};
```

## 4) محاولة "وجه قوي" (pf-*) — ملاحظة

كنت بدأت أضيف نسخة أفاتار أقوى (هالة دوارة + رأس يهتز + عيون تتلون + فم يتكلم) بأسماء classes تبدأ بـ `pf-` (CSS بس، بدون ما أربطها بالـ HTML لسه).

**لكن** لما رفعت الملف آخر مرة، لقيت نسخة **مختلفة وأقوى** جاهزة فيه اسمها `mega-bot` (هالة طاقة، هوائي يهتز، فم equalizer بخمس أعمدة) — هذي مو من سوّاها أنا بهالمحادثة، يبدو انها انضافت من مكان/محادثة ثانية. الملف الحالي عندك يستخدم هذي النسخة (`mega-bot`)، مو نسخة `pf-*` اللي كنت بديتها.
